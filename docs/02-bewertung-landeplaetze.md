# Bewertung der Landeplätze

Die Bewertung dient der groben Etappenplanung. Im Mittelpunkt stehen drei Funktionen:

| Kategorie | Bedeutung |
|---|---|
| Rast | Strand als Pausenpunkt im Plan |
| Getränke | Recherchierte Verkaufsstelle für Getränke bzw. Verpflegung |
| Hotel | Namentlich recherchiertes strandnahes Hotel |

Mehrere Funktionen können zusammen auftreten. Ist nur Rast aufgeführt, wurde keine weitere Versorgung erfasst; das bedeutet nicht automatisch, dass es vor Ort keine gibt.

Je Ort dokumentieren wir Name, Gemeinde, Kartenreferenz, wesentliche Strandmerkmale, Seeseite, bekannte Verkaufsstellen und Hotels, Nachbarstopps sowie Quellen. Entfernungsangaben von Hotels werden als Anbieterangaben übernommen. Eine metergenaue Untersuchung von Ausstieg, Foiltiefe und Fussweg gehört nicht zum gewünschten Detailgrad. Es gibt keine separate Liste offener Ortsprüfungen.

Die Route bleibt als Planungsentwurf bezeichnet. Recherchierte Merkmale wie Sand, Kies, Felsen oder flaches Wasser bleiben als Orientierung erhalten. Die Wind-Simulation folgt in Phase 2.

Hotelöffnung, Zugang und Regeln, Materiallogistik sowie eine gesonderte Belegqualitätsbewertung werden nicht untersucht.
